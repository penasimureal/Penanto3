■適用の仕方  
ダウンロードしたファイルを、ペナントシミュレーション3.4.11フォルダの下においてください。

■設計思想  
もともとのゲームの更新が終わってしまったので、内容を引き継ぎ、UI等は変えないままシミュレーションゲームを維持したまま、追加機能を実装。

■実装機能の方向性  
１．日程  
・オープン戦  
・世界大会の実装  
  
２．画面表示系  
・守備指標の反映  
・調子の反映（直近の試合成績など）  
・連続試合安打等の記録の反映  
・トップ画面含む全体画面の編集  
・ポストシーズン用成績表示  
  
３．機能拡張  
・CPU機能の強化  
―CPU同士のトレード、CPUから自球団へのトレード  
―ポジション追加、コンバートの実施  
―戦力外やドラフトからの選手獲得  
―試合中の守備位置変更、打順の最適化  
―野手登板  
―シーズン中の新戦力補強（支配下登録、外国人選手等）  
・外国人選手獲得方法の変更  
・ゲームロジックの変更による走塁判断の追加  
・背番号0、00  
・試合ごとのスコアや個人成績の見直し
